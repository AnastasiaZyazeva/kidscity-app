Разработка программного модуля для автоматизации оформления билетов в детский парк A4KidsCity

Описание проекта:
Данный проект представляет собой настольное приложение для автоматизации процесса оформления и учета билетов в детском парке A4KidsCity. Система позволяет регистрировать пользователей, оформлять билеты, хранить информацию в базе данных и обеспечивать удобный доступ к данным для сотрудников парка.

Стек технологий:
* Python 3.13
* PyQt6
* PostgreSQL
* psycopg2
* PyCharm Community Edition
* OpenServer (для локального развертывания PostgreSQL)

Запуск проекта:
1. Установить Python 3.13.
2. Установить PostgreSQL и создать базу данных проекта.
3. Выполнить SQL-скрипт создания таблиц из каталога sql.
4. Установить необходимые зависимости: pip install PyQt6 psycopg2
5. Настроить параметры подключения к базе данных в файле конфигурации.
6. Запустить главный файл приложения: python main.py

Содержимое репозитория:
* main.py — основной файл запуска приложения;
* sql/ — SQL-скрипты создания таблиц и заполнения базы данных;
* README.md — инструкция по установке и запуску проекта.

Основные возможности:
* регистрация и авторизация пользователей;
* бронирование билетов;
* просмотр списка оформленных билетов;
* хранение данных в PostgreSQL;
* управление справочной информацией через административную панель.
